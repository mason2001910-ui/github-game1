# 投資農場

給國小學生玩的生活理財與投資策略遊戲。玩家經營農場，分配資金、種植作物、添購設施、面對事件，並在四季市場中決定何時出售或保留收成。

## 開始遊戲

直接用瀏覽器開啟 `index.html`，不需要安裝套件或啟動伺服器。建議使用最新版 Chrome、Edge 或 Firefox。

## 遊戲內容

- 支援 1–4 位玩家輪流遊玩，進行兩年四季。
- 每位玩家以 20 元創業基金開始；第二年春季領取 4 元季節收入。
- 每位玩家最多經營 3 塊田，可在春、夏、秋、冬任一季種植作物。
- 春季可添購灌溉設備、溫室或倉庫。
- 夏季共同事件會帶來天氣、病蟲害、市場或補助變化。
- 秋季收成後可出售產品或保留庫存，之後再依市場價格出售。
- 決策理由、農場任務與風險管理也會列入總分。

## 操作方式

1. 選擇玩家人數並輸入名稱，按「開始春季」。
2. 每位玩家在自己的回合種植、添購設施、收成交易或使用風險管理功能。
3. 點選「完成本季」交給下一位；最後一位完成後，遊戲推進到下一季。
4. 冬季結算後進入下一年，第二年冬季結束時查看總分與反思題。

## 教學用途

適合國小中高年級小組活動。可引導學生比較成本、收入、等待時間與風險，並討論保留現金、分散投資、設施成本及市場波動。

## 技術

本遊戲以單一 HTML 檔實作，樣式與 JavaScript 均內嵌於 `index.html`，無需建置流程或外部依賴，可離線遊玩。
